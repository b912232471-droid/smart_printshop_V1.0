# 位置权限配置指南

## ⚠️ 问题说明

错误信息：
```
getLocation:fail the api need to be declared in the requiredPrivateInfos field in app.json/ext.json
```

这是微信小程序 2.32.3 基础库之后的新要求，需要声明隐私接口。

---

## ✅ 解决方案（已完成）

### 1. app.json 已添加配置

```json
{
  "permission": {
    "scope.userLocation": {
      "desc": "你的位置信息将用于查找最近的打印店网点"
    }
  },
  "requiredPrivateInfos": [
    "getLocation"
  ]
}
```

---

## 🔧 微信开发者工具额外配置

### 步骤1：配置隐私协议（重要！）

1. 打开微信开发者工具
2. 点击菜单栏：**设置** → **项目设置**
3. 找到 **隐私相关设置** 或 **本地设置**
4. ✅ 勾选：**启用隐私相关接口**
5. ✅ 勾选：**不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**（本地开发需要）

### 步骤2：添加隐私协议弹窗（可选）

如果开发者工具要求必须有隐私协议弹窗，可以在首页添加：

**在 index.js 的 onLoad 中添加：**
```javascript
onLoad() {
  // 检查隐私协议
  if (wx.getPrivacySetting) {
    wx.getPrivacySetting({
      success: res => {
        if (res.needAuthorization) {
          // 需要显示隐私弹窗
          this.setData({
            showPrivacy: true
          });
        }
      }
    });
  }
  
  // 其他初始化代码...
}
```

### 步骤3：清除缓存重新编译

1. 微信开发者工具 → **工具** → **清除缓存** → 选择 **全部清除**
2. 点击 **编译** 按钮重新编译
3. 首次打开首页时，会弹出位置授权请求

## 🔍 常见问题

### Q1: 仍然报同样的错误
**A:** 
1. 确保已保存 `app.json`
2. 清除缓存（工具 → 清除缓存 → 全部清除）
3. 重新编译

### Q2: 提示需要用户授权
**A:** 这是正常的，点击"允许"即可

### Q3: 真机调试位置不准
**A:** 
- 确保手机GPS已开启
- 在室外测试效果更好
- 室内可能需要WiFi辅助定位

### Q4: 位置权限被拒绝后如何重新授权
**A:** 
```javascript
wx.openSetting({
  success: (res) => {
    // 根据 res.authSetting 判断用户是否重新授权
  }
})
```
